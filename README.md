# PowerBI_Nossos_Colaboradores
👥 Relatório de Análise de Recursos Humanos

Este projeto apresenta um painel analítico desenvolvido com Power BI com foco no setor de Recursos Humanos. O objetivo é fornecer uma visão clara e interativa sobre os colaboradores da empresa, considerando aspectos como gênero, formação acadêmica, faixa etária, setor, cargo e distribuição salarial.
Segue link para acesso ao relatorio: https://app.powerbi.com/view?r=eyJrIjoiMTg1Zjc1OTgtZmVjMC00MTIxLTlmNjktODA4OWZlYmNhOWVhIiwidCI6Ijg1ZGU1OTA5LTZlOGItNGEwYy1iYTIzLWYwMzYyYzcyZDc3NiJ9

📊 Funcionalidades

    Visão geral dos colaboradores e distribuição por gênero

    Total de salários pagos e média salarial por colaborador

    Formação acadêmica cruzada com gênero

    Distribuição dos colaboradores por cidade e faixa etária

    Comparativo de gênero por setor e por cargo

    Filtros interativos para análise segmentada

🧠 Insights Possíveis

    Identificação de possíveis desigualdades de gênero em cargos ou setores específicos

    Distribuição do nível de formação acadêmica entre os colaboradores

    Perfil etário da equipe para planejamento de sucessão ou ações específicas

    Análise de equilíbrio entre salários e quantidade de colaboradores

🛠️ Tecnologias Utilizadas

    Power BI

    Microsoft Excel (arquivo: Análise de RH.xlsx) como fonte de dados
